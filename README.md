# Muskan’s academic and engineering portfolio

Live at [muskankalonia.github.io](https://muskankalonia.github.io/).

This site uses the MIT-licensed [academic-homepage Jekyll template](https://github.com/luost26/academic-homepage/tree/69f658932b7c912305a861b88a0cadcfac46e071). GitHub Pages publishes from the root of the `main` branch.

To preview locally, install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

Update the bio, education, experience, and skills in `_data/`. Publication entries live in `_publications/` and project entries in `_showcase/`.

The supplied résumé is a local source file and is excluded from both Git and the Jekyll build.
